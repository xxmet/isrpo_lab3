# Text Refactoring

Расширение для VS Code, автоматизирующее рутинные операции с текстом прямо в редакторе.

## Возможности

*   **Конвертация стилей:** Преобразование текста в `camelCase`, `snake_case`, `PascalCase`.
*   **Очистка текста:** Удаление пустых строк, лишних пробелов и дубликатов строк.
*   **Анализ текста (Check Case):** Подсчет количества слов каждого стиля (camelCase, snake_case, PascalCase, CONSTANT_CASE) в текущем файле или выделенном фрагменте.
*   **Визуализация статистики:** Открытие панели с гистограммой, показывающей "замусоренность" файла и соотношение стилей.
*   **Гибкие настройки:** Возможность включать/отключать команды и настраивать допустимое количество пустых строк через стандартное меню Settings.

## Использование

1. Выделите текст в редакторе (или не выделяйте, тогда команда применится ко всему файлу).
2. Нажмите правой кнопкой мыши и выберите нужную команду в разделе **Text Refactoring**.
3. Для просмотра статистики вызовите палитру команд (`Ctrl+Shift+P`) и введите `Show Text Statistics`.

## Настройки

В меню `File -> Preferences -> Settings` найдите `Text Refactoring`. Там можно:
* Включать и выключать отдельные команды.
* Задать максимально допустимое количество пустых строк (`maxEmptyLines`).
